# MCSL-069 Lab Assignment

Only the practical assignment sections **8.1 (Artificial Intelligence)** and
**8.2 (Machine Learning)** are included. Each section has ten session folders.
Every exercise notebook is saved as `a.ipynb`, `b.ipynb`, and so on inside its
session folder, together with the CSV input files used by that exercise.
Notebook outputs are included; open a notebook in Jupyter or VS Code to run it
again.

Small, reproducible CSV datasets are provided so the exercises run locally
without downloading external data. The handwritten-digit exercise uses the
bundled scikit-learn digits dataset, resized to the requested 28x28 input shape.

The notebooks require Python, pandas, NumPy, and scikit-learn. The Deep
Q-Learning and handwritten-digit notebooks additionally use PyTorch.
